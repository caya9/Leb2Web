Praktikum ini bertujuan untuk mempelajari:

- 📊 Pembuatan tabel HTML

- 📋 Penggunaan select dan textarea

---

# 📝 Langkah-Langkah Praktikum

## 1️⃣ Membuat Tabel Data Mahasiswa

Pada langkah pertama dibuat tabel sederhana menggunakan HTML.

Elemen yang digunakan antara lain:

- `<table>` untuk membuat tabel
- `<tr>` untuk membuat baris
- `<th>` untuk membuat header tabel
- `<td>` untuk membuat isi tabel

Data mahasiswa yang digunakan terdiri dari nomor, nama, dan nilai.

---

## 2️⃣ Membuat Tabel Terstruktur

Pada langkah kedua dibuat tabel yang lebih terstruktur menggunakan:

- `<caption>` untuk judul tabel
- `<thead>` untuk bagian kepala tabel
- `<tbody>` untuk isi tabel
- `<tfoot>` untuk bagian bawah tabel

Pada bagian `<tfoot>` ditambahkan nilai rata-rata.

---

## 3️⃣ Membuat Form Registrasi Mahasiswa

Pada langkah ini dibuat form registrasi mahasiswa.

Form digunakan untuk menerima data dari pengguna.

Beberapa input yang digunakan yaitu:

- Nama
- NIM
- Email
- Password

Setiap input diberikan label agar lebih mudah dipahami.

---

## 4️⃣ Membuat Radio Button dan Checkbox

Pada langkah ini digunakan:

### 🔘 Radio Button

Radio button digunakan ketika pengguna hanya dapat memilih **satu pilihan**.

### ☑️ Checkbox

Checkbox digunakan ketika pengguna dapat memilih **lebih dari satu pilihan**.

---

## 5️⃣ Membuat Select dan Textarea

Pada langkah ini digunakan:

- `<select>` untuk membuat pilihan dalam bentuk dropdown.
- `<textarea>` untuk membuat kolom teks yang dapat digunakan untuk menulis keterangan atau informasi tambahan.

---

## 6️⃣ Menambahkan Validasi Form

Pada langkah ini ditambahkan validasi sederhana pada form.

Beberapa atribut validasi yang digunakan yaitu:

- `required`
- `min`
- `max`
- `minlength`

Validasi digunakan agar data yang dimasukkan pengguna sesuai dengan ketentuan yang telah ditentukan.

---

## 7️⃣ Menggunakan Semantic HTML

Pada langkah ini digunakan semantic HTML untuk membuat struktur halaman lebih jelas.

Beberapa elemen semantic yang digunakan antara lain:

- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<footer>`

Penggunaan semantic HTML membantu membedakan bagian-bagian dalam sebuah halaman web.

---

## 8️⃣ Menambahkan Multimedia

Pada langkah ini ditambahkan elemen multimedia berupa audio dan video.

Elemen yang digunakan:

- `<audio>` untuk menampilkan audio.
- `<video>` untuk menampilkan video.

File multimedia disimpan di dalam folder `media`.

---

## 9️⃣ Mini Project - Form Biodata Mahasiswa

Pada bagian mini project dibuat halaman **Form Biodata Mahasiswa**.

Mini project menggabungkan materi yang telah dipelajari sebelumnya, yaitu:

- Semantic HTML
- Tabel
- Form
- Input
- Radio button
- Checkbox
- Select
- Textarea
- Validasi form
- Multimedia

File mini project dibuat dalam file:

`biodata.html`
